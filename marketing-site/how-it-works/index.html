How it works

  1. Say whether this is your first VA disability claim.
  2. Answer the symptom questions. A yes can save a possible condition.
  3. Add the conditions you want on this claim.
  4. Upload a PDF, JPEG, or PNG. You confirm, correct, or set aside each statement.
  5. Add an exam yourself if you have one. The reminder does not name the condition.
  6. A denied, deferred, or reduced issue can start a draft review. The official form is not filled here.
  7. Submit on VA.gov or by mail. Nothing in this product is filed for you.

Vet Buddy can explain what is saved. It can be wrong, and it cannot file the claim or change it.
