# Brand

Initial vector identity for Veteran Claims Buddy. It can be replaced later without changing screens.

| File | What it is |
| --- | --- |
| `logo-mark.svg` | Navy tile and white V. The app uses this file. |
| `logo.svg` | Mark plus the name, for a dark background. |
| `wordmark.svg` | The name alone. |
| `app-icon-source.svg` | 1024 source for a later store icon. Not installed on iOS or Android yet. |
| `brand-tokens.md` | Colors. The app tokens win. |

The mark is a V on navy. It is not a government seal. Colors match `docs/color-scheme.md`. The app bundles the same mark at `app/assets/brand/logo-mark.svg`.
